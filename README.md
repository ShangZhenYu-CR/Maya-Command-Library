# Maya Command Library

Lightweight Maya commands and tools managed through Jira project **MCL**.

## Project links

- Jira: https://coldrain1994.atlassian.net
- Project key: `MCL`
- Workflow: `MCL-WORKFLOW-V1`

## Tool catalog

| Tool | Jira | Purpose | Current attempt |
| --- | --- | --- | --- |
| [MCL Model Renamer](./tools/mcl-model-renamer/) | MCL-1 | Sequential, two-model High/Low, and multi-model spatial auto-pair naming | 0.3.1 / V3 |
| [MCL Proxy Pivot Matcher](./tools/mcl-proxy-pivot-matcher/) | MCL-2 | Batch-match selected final-model pivots from spatially corresponding proxies under `|proxy` | V1 |

## Delivery rule

A feature is not accepted because code exists or tests pass. Fixed-version source/download, launch code, usage, verification scope, and explicit user acceptance are recorded in MCL Jira.
